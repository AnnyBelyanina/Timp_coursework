Сервер вычисления среднего арифметического

## Описание

Серверная программа, которая:
- Принимает подключения от клиентов по протоколу TCP
- Выполняет аутентификацию пользователей с использованием SHA-256 хеширования
- Вычисляет среднее арифметическое для переданных векторов чисел
- Ведет журнал работы программы
- Обрабатывает ошибки без аварийного завершения

## Требования

- Операционная система: Linux (ядро 5.x)
- Компилятор: GCC 7.0+ с поддержкой C++17
- Библиотеки:
  - Boost (program_options)
  - Crypto++ (cryptopp)


# Сборка
make

# Очистка файлов сборки
make clean
